# NewsBreak Local — MVP Demo

交互式 MVP 演示:把 NewsBreak 从「本地新闻流」升级为
**由 Feed 驱动的本地决策引擎**。

完整核心闭环:

```
高频 Feed → 意图触发 → 轻量规划 → 真实行动 → 偏好信号
```

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
```

桌面端会显示一个手机外壳 + 右侧说明栏;手机端自动全屏。

## 体验路径

1. **发现页** — 顶部切换三个垂直场景(约会聚餐 / 周末活动 / 家庭活动)。
2. 在任意卡片上**停留约 2 秒** → 卡片底部弹出「意图触发」入口。
3. 点击意图入口或卡片 → **一键生成轻量行程**(模拟 AI 规划)。
4. 行程页点击「打开地图 / 加入日历」→ 记为**真实本地行动**。
5. **我的页** — 查看偏好信号流、AI 推断的偏好,以及北极星指标
   **WLA(Weekly Local Actions)**。

所有数据均为模拟,无需联网或 API key。状态在刷新后重置。

技术栈:Vite + React 18 + TypeScript。代码结构见 `CLAUDE.md`。
